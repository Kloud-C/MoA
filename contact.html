모아에 의견을 보내주세요

문항의 오류, 이해하기 어려운 안내, 접근성 문제, 새 콘텐츠 제안 등을 환영합니다. 재현 방법이나 해당 페이지 주소를 함께 적으면 확인에 도움이 됩니다.

공개 GitHub Issues로 문의

현재 전용 문의 양식이나 이메일 수집 시스템은 운영하지 않습니다. 문의는 아래 공개 저장소에서 새 Issue로 등록해 주세요. 계정이 필요하며 게시한 글과 GitHub 사용자 이름이 공개될 수 있습니다.

GitHub에서 문의 작성 ↗

공개 Issue에 비밀번호, 전화번호, 이메일 주소, 건강 정보 등 개인 정보나 비밀 정보를 적지 마세요. 문의 내용은 GitHub가 저장하며 GitHub의 개인정보처리방침이 적용됩니다.

응답과 수정

모든 문의에 정해진 응답 시간을 보장하지 않습니다. 오류를 확인하면 영향 범위를 살펴 수정하고, 콘텐츠 기준이나 개인정보 처리 방식이 변경될 때 관련 안내 페이지도 함께 갱신합니다.
