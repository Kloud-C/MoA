모아는 어떤 곳인가요?

모아는 짧은 취향 놀이와 설명이 있는 자기 성찰 콘텐츠를 한 곳에서 즐길 수 있도록 만드는 작은 웹사이트입니다. 결과를 과장하기보다, 어떻게 만들어졌고 어디까지 참고할 수 있는지 함께 설명합니다.

무엇을 제공하나요?

현재 모아에는 8가지 주말 활동을 비교하는 이상형 월드컵, 10개 생활 질문에서 6종 캐릭터를 살펴보는 동물상 놀이, 네 선호 축마다 5문항씩 총 20문항으로 구성한 MBTI 비공식 돌아보기가 있습니다. 각 콘텐츠는 자체 질문과 설명을 사용합니다. 외부 테스트 문항이나 타 사이트 결과를 그대로 복제해 제공하지 않습니다.

사이트는 브라우저에서 바로 작동하는 정적 페이지로 운영합니다. 계정 가입이나 사진 업로드 없이 콘텐츠를 이용할 수 있습니다. 이용 방식은 바뀔 수 있으므로 새 기능이 추가되면 이 안내와 개인정보처리방침을 함께 업데이트합니다.

콘텐츠를 만드는 기준

1. 질문의 목적과 계산 방식을 밝힙니다

게임에는 진행 횟수와 선택 규칙을, 문항형 콘텐츠에는 결과 산출에 사용한 응답 방식을 설명합니다. 결과를 이해하는 데 필요한 정보를 감추지 않습니다.

2. 관찰 가능한 선택을 묻고, 사람을 단정하지 않습니다

짧은 오락성 문항으로 사람의 능력, 건강, 가치, 미래를 판단할 수 없습니다. 동물 이름은 외모 판정이 아닌 결과 표현으로 쓰고, MBTI 문항은 정식 검사라고 주장하지 않습니다.

3. 출처와 한계를 함께 적습니다

외부 자료의 사실을 소개할 때 출처를 연결하고, 자체 제작 질문과 공식 자료의 설명을 구분합니다. 정보가 바뀌거나 오류가 발견되면 확인 후 고칩니다.

4. 광고보다 콘텐츠가 먼저입니다

현재 모아는 광고를 게재하지 않습니다. 광고를 도입할 경우 콘텐츠와 광고를 분명히 구분하고, 동의와 정보 공개 등 필요한 변경을 준비한 뒤 적용합니다.

결과를 어떻게 해석해야 하나요?

결과는 해당 페이지에서 답한 내용에 따라 나온 참고 정보입니다. 월드컵은 선택한 활동의 우승 결과, 동물상 놀이는 답변과 연결한 캐릭터, MBTI 돌아보기는 각 질문에서 선택한 선호 방향을 보여 줍니다. 어떤 결과도 전문적인 심리검사나 의료·법률·교육·채용 판단을 대체하지 않습니다.

누가 운영하나요?

모아는 Kloud-C가 운영하는 개인 프로젝트입니다. 사이트 소스와 변경 기록은 공개 GitHub 저장소에서 볼 수 있습니다. 수정 요청과 개선 의견은 문의 안내를 확인해 주세요.
