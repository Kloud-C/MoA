개인정보처리방침

이 문서는 현재 모아 웹사이트가 작동하는 방식에 맞춰 작성했습니다. 광고, 분석 도구 또는 문의 양식이 추가되면 실제 데이터 흐름에 맞게 이 방침을 수정하고 시행일을 갱신합니다.

1. 운영자와 적용 범위

모아는 Kloud-C가 운영하는 정적 웹사이트입니다. 이 방침은 moa-dej.pages.dev에서 제공하는 홈, 주말 취향 월드컵, 동물상 성향 놀이, MBTI 선호 돌아보기 페이지에 적용됩니다.

2. 테스트 답변과 입력 정보

현재 테스트는 로그인, 이름, 연락처, 사진을 요구하지 않습니다. 답변은 열린 페이지의 브라우저 메모리 안에서 결과를 계산하는 데만 사용하며 모아 서버로 전송하거나 사용자별 기록으로 저장하지 않습니다. 페이지를 새로 고치거나 닫으면 진행 중인 답변은 사라집니다.

3. 쿠키, 광고, 분석 도구

현재 사이트에는 Google AdSense 광고 태그, 자체 분석 도구, 계정 기능이 설치되어 있지 않습니다. 테스트 결과를 저장하기 위한 쿠키나 로컬 저장소도 사용하지 않습니다. 따라서 현재 모아는 방문자를 대상으로 맞춤 광고를 게재하지 않습니다.

향후 광고를 도입할 경우 광고 제공자(예: Google)가 광고를 제공·측정하는 과정에서 쿠키 또는 이에 준하는 기술을 사용할 수 있습니다. 광고 제공자를 식별하고 관련 선택·동의 안내를 마련한 뒤 광고를 적용하겠습니다. Google은 게시자에게 광고 쿠키와 개인 맞춤 광고에 관한 정보 공개를 요구합니다. 사용자는 Google 광고 설정에서 개인 맞춤 광고 설정을 확인할 수 있습니다. 유럽경제지역·영국·스위스 사용자에게 광고를 제공하는 경우 Google의 현재 동의 관리 요구사항도 확인하겠습니다.

4. 웹 호스팅과 접속 정보

웹사이트 파일은 Cloudflare Pages에서 제공됩니다. 브라우저가 사이트를 요청하면 인프라 운영에 필요한 네트워크 정보가 호스팅 제공자에게 전달될 수 있습니다. 모아는 자체 방문자 로그 분석을 활성화하지 않았습니다. Cloudflare의 데이터 처리에 관한 내용은 Cloudflare 개인정보처리방침을 확인해 주세요.

5. 문의

현재 별도 문의 양식이나 이메일 수집 기능은 없습니다. 의견은 GitHub 저장소의 Issues를 통해 전달할 수 있습니다. Issues에 작성한 내용은 공개될 수 있고 GitHub가 관리합니다. 비밀번호, 연락처, 건강 정보 등 공개하면 안 되는 개인정보는 적지 말아 주세요.

6. 방침 변경

사이트 기능, 광고 또는 관련 법령·정책이 바뀌면 이 문서를 업데이트하고 이 페이지의 시행일을 바꿉니다. 중요한 변경은 사이트에서 확인할 수 있도록 안내하겠습니다.

광고 도입 전 확인: 실제 광고 태그, 사용 광고 기술 제공자, 지역별 동의 화면 및 데이터 처리 항목을 확정한 뒤 이 방침을 다시 검토해야 합니다. 현재의 안내는 미래 기능을 이미 사용 중인 것처럼 설명하지 않습니다.
